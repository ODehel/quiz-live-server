## Leçons de méthode
- La sonde avant l'assertion : les six cas de blancs se rattachent à une règle écrite (CA-6, #52, #71) ; aucun trou de CDC.
- Le mutant `override` écrit `injecting env` sur la sortie standard (dotenv 17) : rejoué avec `quiet: true`, seuls les deux tests de priorité le tuent, ce qui montre qu'ils mordent sur l'ordre et non sur du bruit.
- Un mutant « valeur reprise dans le message » n'est tué que par les tests de l'environnement : les nouveaux tests n'ont pas besoin de le redire (le message est le même quelle que soit l'origine de la valeur).
