## Leçons de méthode

- **Un test né vert se prouve par mutation, sur chaque axe** : pour chaque CA, deux assertions (statut `400`, `authenticate` non appelé) ; le mutant les fait échouer toutes les deux, donc aucune n'est redondante par accident.
- **Le test de CA-10 envoyait `{ login }`** : un champ inconnu, pas un `password` manquant. Le libellé d'un test ne dit pas ce que le corps de la requête exerce : le corps se relit.
