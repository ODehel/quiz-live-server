## Leçons de méthode

- **Un test peut naître vert par accident** : « ne supprime rien » passait parce que `deleteQuestion` n'existait pas (`TypeError` attrapé par `toThrow()`). Le vert minimal sans garde l'a rendu rouge pour la bonne raison : l'ordre vert-sans-garde puis garde est ce qui a prouvé le test.
- **Ajouter une méthode à une interface oblige les doubles** : quatre montages à modifier, comme la dette l'annonçait. `tsc` l'a signalé, pas Vitest.
- **La 3ᵉ occurrence d'une dette déclenche une décision explicite** : réduite à une instance locale, pas injectée (injection = quatre fichiers hors périmètre).
