## Leçons de méthode
- L'hypothèse du brief était juste mais incomplète : le côté fragile n'était pas trois tests mais tout le fichier (`port = 3000` partagé par chaque `server.start()`). Les trois échecs du CI sont ceux que la fenêtre de collision a touchés ; la sonde déterministe (3000 tenu en externe) les révèle tous.
- Port `0` pour les tests qui ne lisent pas le port : pas de réservation, donc pas de fenêtre de course. Les tests qui lisent « 3000 » dans un message gardent leur assertion mais n'ouvrent plus de socket (`listen` remplacé sur l'instance Fastify privée par `server['app']`).
- La sonde constate, elle ne décide : un port fixe autre que 3000 (3001, par exemple) survivrait à la sonde ; seule la lecture du code l'écarte.
