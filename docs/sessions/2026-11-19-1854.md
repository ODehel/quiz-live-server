## Leçons de méthode
- Un mutant « écrit en lecture seule » doit écrire quelque chose de neuf à chaque lancement : un `CREATE TABLE IF NOT EXISTS` déjà fait par le lancement de référence est un no-op, donc un faux survivant.
- Le `dotenv` appelé explicitement (`config()`) écrit une bannière sur la sortie standard, pas `import 'dotenv/config'` : un mutant sur le `.env` doit passer `quiet: true`.
- Sans `nodejs.org` (proxy), Node 26 s'obtient par le paquet npm `node@26`, et `better-sqlite3` 13 n'a pas besoin de compilation.
- Le test non-root demande une copie du dépôt qui appartient à l'utilisateur non-root (`cp -a src/.` pour resynchroniser) et un `TMPDIR` à lui.
