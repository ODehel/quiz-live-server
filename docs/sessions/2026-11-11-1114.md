## Leçons de méthode

- **L'agent frais écrit à partir des CDC seuls et voit ce que le code masque** : il a relevé les noms `JWT_*` que la recette (tirée du code) contredisait.
- **Rejouer un délai sans l'attendre** : `vi.useFakeTimers({ toFake: ['Date'] })` suffit, la bibliothèque calcule le temps restant avec `Date.now()` ; le reste (timers, I/O) reste réel.
- **Un test né vert ne tue pas tous les mutants** : celui du premier `429` ne voit ni le hook supprimé ni la condition inversée ; c'est le test du `429` retardé qui les tue. À dire en revue plutôt qu'à gonfler.
- **Environnement** : Node 22, `npm ci --ignore-scripts`, pas de PowerShell, `scripts/session-close.ps1` non exécuté : handoff écrit à la main sur le modèle de `TEMPLATE.md`.
