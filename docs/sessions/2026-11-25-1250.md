## Leçons de méthode
- Une décision qui touche un compteur partagé entre plugins est vérifiable dans le code avant d'être écrite : `rateLimitMiddleware` est appelé par chaque plugin, et le hook du `405` et le gestionnaire de route inconnue appellent chacun la limite ; le `feat` devra éviter de compter une requête deux fois.
- Un trou de CDC voisin a été relevé et laissé tel quel : US-009 CA-26 fixe une limite propre aux connexions `/ws` ; elle n'est ni un `429` ni dite dans ou hors du compteur commun.
