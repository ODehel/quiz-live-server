## Choix d'implémentation (non observables, à challenger)
- Les espions n'étaient pas vidés entre les tests : sans `clearMocks`, un `toHaveBeenCalledWith` pouvait passer grâce aux appels d'un autre bloc. `mockClear` avant chaque test et `mockRestore` après, dans ces trois blocs seulement (seuls `spyOn(console)` du dépôt).
- Le port des messages est testé avec un port libre réservé (`reserveFreePort`, même fenêtre de course que la dette de CA-1), parce que le serveur écoute vraiment.
- Les nouveaux tests recréent le serveur dans le test (le `beforeEach` en construit déjà un, arrêté sans avoir écouté).

## Leçons de méthode
- Un test né vert peut l'être parce que ses données ne forcent rien : un réseau à une seule interface et un port fixé à 3000 ne prouvent ni « première », ni « non-loopback », ni la configuration. Sonder les mutants avant de choisir la cible a évité de bâtir CA-5 sur un port jamais prouvé dans les messages.
- Les espions partagés d'un fichier faussent `toHaveBeenCalledWith` : vider avant de mesurer.
