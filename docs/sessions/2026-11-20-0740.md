## Leçons de méthode
- Un modèle copié tel quel en `.env` ne doit pas changer le comportement : une variable facultative écrite avec une valeur vide est refusée (`SQLITE_DB_PATH`, décision #59) ou traitée comme absente (`BCRYPT_COST`). D'où la forme `# NOM=défaut`, avec la règle sur une ligne de commentaire au-dessus (une ligne `# NOM=défaut (règle)` n'est plus décommentable telle quelle).
- Le test s'appuie sur `dotenv.parse`, la bibliothèque que lit le seed : « exactement les onze variables » se juge sur ce que `dotenv` produit, pas sur une regex maison.
