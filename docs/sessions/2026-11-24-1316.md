## Leçons de méthode
- Choix de découpage (hors CDC) : un `describe` propre à `HEAD` plutôt que `HEAD` dans la liste `methods` du `describe` existant, car `HEAD` n'a pas de corps de réponse : les assertions de corps standard de ce `describe` ne s'y appliquent pas. Aucun test `429` pour `HEAD`, laissé en dette.
- Le constat `HEAD` + corps passe par `server.inject`, pas par une socket réelle : le smoke test du 2026-11-24 (`HEAD` du token sans corps) reste le seul constat sur HTTP réel.
