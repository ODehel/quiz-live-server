## Choix à challenger
- **(a) Le contrôle du chemin vit dans le constructeur de `ProcessEnvironment`**, qui peut maintenant lever. Alternative : une méthode ou une fonction appelée explicitement par `index.ts` et `seed.ts`. J'ai retenu le constructeur : `ProcessEnvironment` est déjà le point d'entrée commun, le seed ne peut pas l'oublier, et la place dans l'ordre (après `PORT`) est tenue par la composition. Contrepartie : un `new ProcessEnvironment()` n'est plus sans risque.
- **(b) Parcours explicite plutôt qu'expression régulière** : liste dans un `Set`, deux boucles. Une expression régulière avec `^[...]+|[...]+$` est quadratique sur une longue suite de blancs ; ici le coût est linéaire. Non observable.
- **(c) `createServer()` autour de toute la composition**, plutôt que quelques lignes dans le `try`. Toute erreur synchrone de composition passe maintenant par `Server starting failed: …` (le CDC est muet sur ces autres erreurs ; voir DEBTS point 5).
- **(d) Seed : `async function seed()`** plutôt qu'un `try`/`catch` synchrone en plus du `.catch` : une seule capture, pas de seconde copie du message d'échec (la dette « écrite deux fois » ne passe pas à trois).
- **(e) Tests du seed par `spawnSync`**, du hub par `spawn` (style de `index.test.ts`) : les deux restent par processus enfant.
- **(f) Rouge des refus de blancs du hub = « le hub tourne encore »** (expiration à 20 s), pas un `expect` : le comportement fautif est précisément que le hub n'a pas refusé.
- **(g) Pas de décision #65** : aucun choix observable pris ; le nom, le découpage et le mécanisme sont non observables. À reconsidérer si Olivier veut tracer (a).
- **(h) Identité de commit** : celle d'Olivier, comme le prescrit `WORKFLOW.md` (le clone porte l'identité `Claude` en configuration locale, non modifiée).

## Leçons de méthode
- Réécrire un module en doublure d'abord (qui rend la valeur brute) donne des rouges sur assertion plutôt que sur import ; à garder pour les modules purs nouveaux.
- Le tool d'écriture a converti des séquences `\uXXXX` en caractères littéraux dans les fichiers écrits : un passage de contrôle `grep -P '[^\x00-\x7F]'` sur les fichiers de test est utile quand ils portent des blancs exotiques.
- Pour tester un refus, un rouge « le processus tourne encore » coûte 20 s par cas : prévoir un délai plus court pour ces tests ou filtrer lors de l'essai.
