## Leçons de méthode

- **Le handoff peut sous-estimer un risque** : « partiel » cachait un écrasement silencieux. Relire le code avant de classer la gravité.
- **Un rouge de route n'a pas toujours lieu** : la traduction existait. Le test de route est une spec née verte, prouvée par mutation, pas un cycle TDD.
- **Le lint relève aussi les tests** : préférer un helper aux déstructurations jetables.
