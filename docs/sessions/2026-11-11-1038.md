## Leçons de méthode

- **`@fastify/rate-limit` ne limite pas le `404` tout seul** : son hook global passe par `onRoute`, le `setNotFoundHandler` n'est pas une route ; il faut `preHandler: app.rateLimit()` sur le handler. Prouvé par le rouge 2 (404 à la place de 429), pas supposé.
- **Un mock de config sans la vraie limite casse le plugin** : `app.rateLimit()` n'existe que si le plugin est enregistré, donc les configs de test utilisent le vrai `rateLimitMiddleware` avec une limite haute plutôt qu'un no-op.
- **Environnement** : Node 22, `npm ci --ignore-scripts` (pas de `better-sqlite3` natif : aucun hub réel lancé ici, d'où le smoke test d'Olivier), pas de PowerShell.
