## Leçons de méthode

- **Un test né vert doit pouvoir échouer pour la bonne raison** : avec un validateur simulé qui répondait `false` partout, le cas « sans token » aurait survécu à la suppression du contrôle d'absence. Le simulé répond `true` pour ce cas, donc seule l'absence du token peut produire le `401`.
- **Le middleware ne distingue pas un token invalide d'un token expiré** (même `validateToken`) : un seul cas « token refusé », pas de cas « expiré » dédié.
- **Environnement** : Node 22, `npm ci --ignore-scripts`, pas de PowerShell ; git configuré à l'identité d'Olivier pour le commit, comme les sessions précédentes.
