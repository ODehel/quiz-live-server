## Leçons de méthode

- **Un validateur qui convertit en chaîne laisse passer un tableau** : `UuidFormatValidator` utilise `RegExp.test`, qui convertit son argument ; `[uuid]` aurait passé. Le cas « tableau contenant l'id de l'URL » a été mis dans les rouges pour forcer le `typeof`.
- **Mon premier script de mutation était faux** : un motif présent aussi dans le `GET` n'a pas été appliqué, et le résultat affiché venait de la mutation précédente. Une mutation se vérifie par un `git diff` avant le run.
- **Relevé de la matrice** : le service étiquette `CA-001` sur trois chiffres ; un motif strict `CA-1` aurait effacé quatorze ✅. Motif retenu : `CA-0*<n>`.
- **Environnement** : Node 22, `npm ci --ignore-scripts` obligatoire ; pas de PowerShell.
