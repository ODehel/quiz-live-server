## Leçons de méthode

- **Le cadrage annonçait un `DELETE` « né vert » : c'était faux.** L'attente existante de CA-29 affirmait l'ancien corps ; elle est tombée au vert de `sendError`, branche partagée, donc c'est un rouge différé, pas un spec test. Durcir l'attente d'un test existant est un rouge valide, mais sur une branche partagée un seul vert en fait tomber plusieurs.
- **Le seed n'insère que sur une table vide.** Une `smoke.db` laissée par un passage précédent garde ses anciens mots de passe sans message d'erreur, et le script s'arrête à `POST /token`. À faire avant chaque smoke test : supprimer `smoke.db`, `smoke.db-wal` et `smoke.db-shm`. Cause non confirmée ici, mais le second passage l'a corrigée.
- **Retirer le marquage `GAP` dans la session qui solde l'écart** a servi de preuve : les trois contrôles sont passés `PASS`, sans autre changement du script.
- **Le hook de fin de session a signalé un commit « non poussé »** deux fois alors que la branche distante pointait sur `4493cfa` (vérifié par `git ls-remote`). Faux positif, quatrième session de suite.
- **Route PR qui marche, reconfirmée** : `gh api repos/ODehel/quiz-live-server/pulls -f title=… -f head=… -f base=main -F body=@fichier`.
