## Leçons de méthode

- **Le filet existant a joué** : le test de CA-47 est passé au rouge dès le vert minimal, sans que j'aie à l'imaginer. Un retrait de parseur à portée plugin est exactement le genre de changement dont un test voisin révèle l'effet de bord.
- **Une ligne a rendu verts trois tests sur quatre** : le `PUT` et les cas `xml` n'ont pas eu de rouge propre. Honnête côté méthode (spec tests + mutations), mais « un rouge par route » annoncé au cadrage n'a pas tenu : le design retenu partage le comportement entre les routes.
- **Sonde avant/après** : observer l'état avant correctif sur hub réel a donné la formulation exacte de la dette (le `TYPE_CHANGE_NOT_ALLOWED` trompeur du `PUT`), qu'un test unitaire n'aurait pas montré.
- **Hook de fin de session** : il a signalé à tort un commit non poussé (le clone superficiel ignorait `origin/session/*`). Vérifié par `git ls-remote` avant d'agir ; piège déjà noté dans `WORKFLOW.md`.
