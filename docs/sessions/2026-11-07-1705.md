## Leçons de méthode

- **Les défauts du script ne tenaient pas** : `ProcessEnvironment` et le script retombent sur `admin123` / `player123`, que le seed refuse (`Invalid password`). Trouvé en lançant le seed pour la sonde. Le script n'est utilisable qu'avec les variables d'environnement ; la dette est consignée.
- **Un contrôle de rôle peut créer des données sur un hub non conforme** : le `POST` du joueur retient l'id dans `$script:CreatedIds` s'il répond `201`, pour que le nettoyage final le supprime. Vu pendant la mutation de la sonde.
- **Pas de rouge honnête sur un script sans PowerShell** : la sonde `curl` prouve ce que le script vérifie, pas que son code PowerShell est juste. Le verdict est le smoke test d'Olivier.
