## Leçons de méthode
- Piège rencontré : `git checkout <fichier>` pour restaurer après un mutant restaure l'index, pas la modification non indexée. Le premier mutant a donc écrasé le `.env.example` neuf, et les sept suivants ont tourné contre l'ancien contenu (échecs trompeurs). Corrigé : fichier indexé avant les mutants, mutants rejoués. À faire à chaque session de mutation : indexer (ou copier) avant de muter.
- Le minimum du CA-4 est écrit en dur dans `owasp-password-validator.ts` (non exporté). Sans toucher à `src/`, le test le lit depuis le validateur (plus petite longueur acceptée), au lieu de recopier 12.
- Un test processus « refusé » seul ne prouve pas que le `.env` est lu (un mot de passe manquant donne aussi le code 1 et le préfixe) : d'où le test de contrôle (copie éditée, acceptée, onze comptes).
