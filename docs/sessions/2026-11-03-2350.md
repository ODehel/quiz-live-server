## Leçons de méthode

- **Une fonction partagée impose l'ordre des rouges** : le vert du `POST` aurait cassé l'ancien test `PUT` ; les deux rouges ont donc été écrits avant l'unique vert. Les mutants vérifient que chacun des deux tests tombe seul sur chaque mutation.
- **Le test CA-21 s'appelle « should trim the new name »** alors qu'il vérifie un nom invalide : libellé trompeur, non corrigé (hors périmètre), à renommer à l'occasion.
- **Les messages de test sont inventés** (`'Theme name is invalid.'`) : la route est testée avec un service simulé, le texte réel du service n'est pas asserté à cette couche.
- **Environnement** : pas de smoke test côté Claude ; les chiffres attendus du script sont une prévision, pas un relevé.
