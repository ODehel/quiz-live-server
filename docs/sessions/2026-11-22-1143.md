## Leçons de méthode
- Un hook `async` sans `await` échoue au lint (`@typescript-eslint/require-await`) : le lint a été lancé avant le commit et a attrapé la première forme.
- Un test né vert peut être masqué par le code ajouté (le hook intercepte avant le comportement natif) : le mutant utile retire le hook et ajoute un parseur `*`, pas le hook seul.
- Le `415` ne passe pas par `onRequest` avant le rate limit : l'ordre `429` puis `415` est celui du plugin (le rate limit est enregistré avant), non spécifié par un CDC et non testé.
