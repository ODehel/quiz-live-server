## Leçons de méthode
- Le coût d'un test sur processus réel (un `tsx` par cas) borne le produit des cas : « absent » est prouvé pour les onze comptes, les valeurs refusées pour le premier (`admin`) et le dernier (`quiz_buzzer_10`) de l'ordre seulement, la politique ne dépendant pas du compte. 45 tests, une dizaine de secondes.
- Le libellé après `User seeding failed: ` n'est pas asserté (non normatif, CA-4) : le test fixe le préfixe, le compte nommé (et aucun autre), l'absence du mot de passe, le code `1`, la sortie standard vide et l'absence de pile.
- Un mutant « espace de bordure refusée » a été ajouté après coup : le CDC dit « pas uniquement des espaces », pas « sans espace en bordure » ; les deux cas d'acceptation (espaces autour d'un caractère visible) le tuent.
- Le script de mutation (hors dépôt) remplace une chaîne unique, lance le bloc ciblé de la suite et restaure le fichier à chaque mutant.
