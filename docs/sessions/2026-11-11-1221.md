## Leçons de méthode

- **Un nom de variable est un contrat avec l'opérateur** : un `.env` écrit d'après le CDC est aujourd'hui ignoré en silence par le hub (`JWT_SECRET` posée, `JWT_SECRET_KEY` lue). La dette est donc classée avant tout déploiement, pas seulement « à aligner ».
- **Un « obligatoire » du CDC ne dit pas toujours ce qui arrive en son absence** : US-002 le dit pour le seed (arrêt avec message), pas pour le secret JWT. Écrit comme tel dans la décision et dans la dette, sans inventer de refus de démarrage.
- **Clone shallow** : `git log -p` sur un handoff précédent demande `git fetch --deepen=40 origin main` ; sans cela, un seul commit est visible.
- **Environnement** : Node 22, `npm ci --ignore-scripts`, pas de PowerShell, handoff écrit à la main sur le modèle de `TEMPLATE.md`.
