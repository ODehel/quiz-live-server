## Diff de `DEBTS.md`

Ligne `PUT /api/v1/questions/:id` : ajout de la clause « l'`id` du body n'est pas contrôlé comme UUID : un `id` mal formé et différent de l'URL répond `ID_MISMATCH`, pas `INVALID_UUID`, priorité à trancher sous CA-35 ». Rien de soldé.

## Leçons de méthode

- **Le test né vert « id identique → 200 » est volontaire** : la spec dit « s'il l'est, il doit correspondre », donc le cas conforme doit être verrouillé, sinon une garde trop large (M1) passerait inaperçue.
- **Sonde trop pauvre** : rejouer le `PUT` incohérent avec les mêmes données ne montre pas qu'il ne modifie rien. Pour un refus, la sonde et le smoke test doivent changer une donnée visible.
- **`cut` sur la sortie de `curl -w`** a tronqué la ligne de statut : ne pas couper une sortie qui porte le code HTTP.
