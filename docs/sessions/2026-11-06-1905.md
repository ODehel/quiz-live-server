## Leçons de méthode

- **Le cadrage a tenu.** Un rouge, un vert, aucun refactor : le montage dupliqué est noté en dette plutôt qu'extrait (règle de la troisième occurrence).
- **Un test négatif né vert ne vaut que par son mutant.** « Un `409` ne journalise rien » ne sert que si le mutant « appel hissé en tête de `sendError` » existe ; c'est le seul des quatre que le test de log ne tue pas. Sans lui, le test serait décoratif.
- **Le test négatif asserte aussi le statut `409`.** Sinon `logLines` vide pourrait venir d'une requête qui n'a jamais atteint `sendError`.
- **Le skill `tdd-session-close` et le gabarit du dépôt divergent.** Le skill décrit un récap en dix sections ; `docs/sessions/TEMPLATE.md` en a cinq. J'ai suivi le gabarit du dépôt, source de vérité du WORKFLOW, comme le handoff précédent. À aligner dans une session dédiée sur le skill.
- **Le WORKFLOW dit « pas de second commit » pour le handoff, mais il est demandé après l'ouverture de la PR.** Sans force push, il part en second commit de la branche ; le squash ramène `main` à un seul commit.
- **Le hook de fin de session a signalé un commit « non poussé »** alors que la branche distante pointait sur `8c4c078` (vérifié par `git ls-remote`). Faux positif, troisième session de suite.
- **Route PR qui marche, confirmée** : `gh api repos/ODehel/quiz-live-server/pulls -f title=… -f head=… -f base=main -F body=@fichier`.
