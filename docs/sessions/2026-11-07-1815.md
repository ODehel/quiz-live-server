## Leçons de méthode

- **Un gestionnaire d'erreur qui remplace celui du parent doit lui déléguer** : `reply.send(error)` renvoyait `200` au `429` du rate limit, qui lève un objet simple et non une `Error`. C'est le test CA-13, déjà vert, qui l'a attrapé. Ne jamais lancer le seul fichier du cycle : le fichier entier suffisait ici, mais la suite complète reste le filet.
- **Le corps vide et le JSON tronqué sont deux codes Fastify distincts** (`FST_ERR_CTP_EMPTY_JSON_BODY` / `FST_ERR_CTP_INVALID_JSON_BODY`) : un seul test ne couvre pas les deux, une mutation par code l'a confirmé.
