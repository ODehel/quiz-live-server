## Leçons de méthode
- **Reproduction** : l'échec est rare (1 sur 50 sous charge ; 1 sur 3 suites complètes au 1315, où 39 fichiers se disputent le processeur). La boucle d'un seul test sous charge suffit à l'observer, mais il faut une cinquantaine d'essais ; un taux « 0 sur 50 » après correction prouve peu en soi, c'est la lecture du code qui fonde la correction (`app.listen` résolu, puis deux `console.log` : le port accepte les connexions avant l'annonce) et la mutation (b) qui prouve que l'assertion porte sur l'annonce.
- **Assertion plus juste qu'avant** : l'ancienne assertion lisait `hub.console()`, qui mêle les deux sorties et les lignes JSON de Fastify (`Server listening at http://…:<port>`, qui contiennent aussi `:<port>`). Elle pouvait donc être satisfaite sans l'annonce du hub. `startupLines` écarte ces lignes JSON : la mutation (b) l'aurait peut-être laissée passer avec l'ancienne forme, pas avec la nouvelle.
- **Autres tests exposés** : aucun. Les tests qui lisent la sortie après `waitUntilListening` attendent d'abord le message (`waitForStandardOutput`, `waitForStartupAnnouncement`) : CA-2 et CA-3 (messages sur la sortie standard, ligne 268), CA-1 (processus vivant, ligne 282). Un seul lit une sortie après `waitUntilListening` sans attendre : `US-001/CA-10 does not refuse %s alone…` (assertion `hub.errors()` ne contient pas `SQLITE_DB_PATH`) ; c'est une assertion d'absence, qui ne peut pas échouer par la course (elle peut seulement être verte trop tôt), et le hub qui écoute n'a pas échoué au démarrage ; pas de dette. Les tests `CA-7`, `CA-8`, `.env` vide lisent après `exitOf` (processus terminé) : sans course.
- **Écart `DEBTS.md` / réel (toujours non corrigé)** : la dette « `index.ts` et `seed.ts` sans test » écrit que le câblage du contrôle JWT n'est pas testé ; `index.test.ts` le prouve sur processus réel pour `JWT_SECRET` trop court et `JWT_EXPIRATION=abc` (code `1`, une seule erreur, nom de la variable), et « l'ordre JWT puis PORT » en CA-10. À corriger dans la session `test(startup)` `JWT_SECRET` absent ou vide.
- La sandbox n'a pas d'IPv4 non-loopback garantie : les tests d'adresse (CA-1 sur interface, CA-3) peuvent se sauter ; ils ne l'ont pas été ici (1026 verts sans saut signalé), mais ce n'est pas une garantie CI.
