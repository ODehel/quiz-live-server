## Leçons de méthode
- **Un test né vert doit viser les mutants plausibles avant d'être écrit.** Mes ids croissaient avec les dates : `ORDER BY id DESC` seul survivait. Choisir les fixtures pour que chaque mutant plausible donne un résultat différent.
- **Lancer le lint dès le premier vert**, pas après les mutations : `response.json()` non typé a coûté un aller-retour.
- **Le récap précédent était périmé sur le HEAD** (quatre PR de documentation fusionnées entre-temps) mais juste sur le code. Le rituel l'a montré en une commande.
- **Environnement de Claude** : le build natif de `better-sqlite3` est bloqué (headers Node refusés par le réseau) ; `npm ci --ignore-scripts` suffit pour `tsc`, lint et tests. `gh pr create` échoue (GraphQL interdit) : utiliser `gh api repos/ODehel/quiz-live-server/pulls`. Le hook de fin de session voit une branche « sans référence distante » après le push : `git fetch origin '+refs/heads/<b>:refs/remotes/origin/<b>'`.
- **Pas de `pwsh` chez Claude** : `session-close.ps1` n'a pas pu tourner, ce handoff est écrit à la main d'après `TEMPLATE.md`.
- **Handoff dans un second commit de la PR** (pas d'amend, pas de force push) ; le `squash` le fusionne avec le commit de code.
