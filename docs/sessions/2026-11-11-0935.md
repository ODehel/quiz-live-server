## Leçons de méthode

- **Un test né vert se prouve par mutation par route** : `config: { rateLimit: false }` isole une route à la fois ; un mutant global seul n'aurait pas prouvé que chaque route (le `DELETE` vit dans un plugin enfant) est couverte.
- **Chaque requête vise la route testée** : la limite est partagée par le plugin ; épuiser la limite sur une autre route ne prouverait rien sur celle-ci.
- **Environnement** : Node 22, `npm ci --ignore-scripts`, pas de PowerShell.
