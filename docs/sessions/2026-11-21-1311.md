## Leçons de méthode
- Le premier commit ne pouvait pas tuer le mutant `11` à l'appel : la liste des comptes est faite de constantes. Faire rendre le nombre par le repository crée la couture : un faux repository qui rend 3 donne « 3 comptes créés », et le mutant `11` est tué.
- Changer le type de retour d'`insertAllIfEmpty` oblige à toucher les fakes déclarés ailleurs (`authentication-service.test.ts`) : le `grep` sur tout `src/` les a trouvés, `tsc` aurait refusé sinon.
- Les anciens handoffs (`docs/sessions/`) citent encore le « 11 » en dur : ils sont historiques, non réécrits.
