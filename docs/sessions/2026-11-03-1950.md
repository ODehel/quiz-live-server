## Leçons de méthode

- **Le filet a mordu** : en scindant `formatName`, j'ai d'abord oublié l'appel à `ensureNameIsFree` dans `createTheme`. Le test CA-4 de création l'a signalé au premier run. Les tests de création portent donc bien l'unicité, indépendamment du `PUT`.
- **Les tests CA-22 existants étaient vides de sens** : dépôt simulé qui ne retrouve jamais rien, assertions dans un `afterEach`. Le nouveau `describe` simule le comportement réel du dépôt. Les deux anciens tests restent, non touchés.
- **Le seed exige deux mots de passe d'au moins 12 caractères** : ma première procédure de smoke test n'en fixait qu'un (`ADMIN_PASSWORD`), le défaut de `BUZZER_DEFAULT_PASSWORD` (9 caractères) a fait échouer le seed, donc un `401` sur une base vide. Corrigé en fixant les deux variables ; les défauts qui ne peuvent pas passer le validateur sont consignés en dette.
- **Environnement** : le téléchargement des en-têtes de Node est refusé dans l'environnement de Claude ; `npm ci --ignore-scripts` suffit pour `tsc`, le lint et les tests unitaires.
