## Leçons de méthode
- **Une sonde constate, l'énoncé de la décision peut être plus large** : « base existante en lecture seule » était vrai pour la base du hub (trois tables) et faux pour une base créée par le seed seul. Premier essai raté à cause de ma préparation ; la préparation d'une base d'essai doit reproduire ce que le hub écrit, pas celui du seed.
- Les permissions ne valent rien sous root : tout se sonde sous un compte dédié (`probe`), et un test à venir devra se sauter explicitement sous root et sous Windows.
- Le CDC écrit « sondé le 2026-11-18, Linux non-root » et dit que Windows n'est pas sondé : une règle de lecture seule peut différer sous NTFS.
