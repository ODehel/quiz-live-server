## Ce qui change (comportement observable du `PUT`)
- `:id` du chemin mal formé : `400 INVALID_UUID` (forme seule, toute version : le `PUT` utilise sa propre instance de `UuidFormatValidator`).
- Corps JSON qui n'est pas un objet (`null`, tableau, chaîne, nombre, booléen) : `400 INVALID_BODY`, `Request body must be a JSON object.`
- `id` du corps mal formé ou non chaîne : `400 INVALID_UUID` ; bien formé mais différent : `400 ID_MISMATCH` (avant : `ID_MISMATCH` pour tout écart).
- `name` non `null` non chaîne : `400 VALIDATION_ERROR`, `Theme name must be a string.` ; absent ou `null` : `Theme name is required.` (avant : `500`).
- Champs inconnus jugés après le `name` (avant : en premier).
- Forme du `name` jugée avant le `404` (service : `formatName` avant `getById`) : un nom invalide sur un id inconnu répond `400`, plus `404`.
- Constante `INVALID_BODY` créée dans `src/common/error-codes.ts`.
